# Private messaging

Mode: Operate. Native iOS and Android. Extend the existing Stitch-derived Palla design system.

## Direction contract

THESIS: Compact private conversations help organizers coordinate directly with players. Use four bottom tabs, with Messages before Profile; organizer roster actions also open conversations. The header keeps the notification bell.

OWN-WORLD: Hanken typography, pale lavender background, white and lavender message bubbles with fine borders, dark text, lime unread counts and send action. Ghost back controls and accessible native touch targets.

STORY: Notice unread messages, find a conversation, read context, reply, and recover a failed send without duplicating it.

FIRST VIEWPORT: Inbox has a back control, Messages title, search, All/Unread/Upcoming/Past filters, rounded bordered conversation cards. Conversation has participant identity and role, optional session context, chronological bubbles and a bottom composer above the keyboard.

FORM: Incumbent design extension, approved revised compact inbox and previously approved conversation mockup. Keep search/filter controls and all real states within this visual language.

CONSTRAINTS: No player start-chat UI yet. Backend does not require registration. Text-only private organizer/player pairs; no attachments or push notifications. Online presence is approved and implemented as an ephemeral foreground connection hint, without last-seen history. Ephemeral typing hints and read/delivery receipts are implemented. A grey single check means saved to the server; two green checks mean read by the recipient, using the existing accent-green token. Two grey checks acknowledge receipt by the foreground recipient app; this is not push delivery. All preview content is synthetic and explicitly labelled.
